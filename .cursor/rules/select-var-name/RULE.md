# Variable Naming Standards

When writing code, always ensure variable names are:

- **Logical**: Names should reflect the purpose and meaning of the variable
- **Correct**: Use appropriate naming conventions for the programming language
- **Understandable**: Names should be clear and self-documenting

## Best Practices

- Use descriptive names that explain what the variable represents
- Follow language-specific naming conventions (camelCase, snake_case, PascalCase, etc.)
- Avoid abbreviations unless they are widely understood
- Prefer longer, descriptive names over short, cryptic ones
- Use consistent naming patterns throughout the codebase

## Examples

**Good:**
- `userAccountBalance`
- `isAuthenticated`
- `maxRetryAttempts`
- `calculateTotalPrice()`

**Bad:**
- `x`, `temp`, `data`
- `flag`, `val`, `obj`
- `calc()`, `proc()`, `fn()`
